# JukeBox

JukeBox is a Python-based desktop application developed as part of university coursework, focused on object-oriented programming, GUI development, and structured software design.

## Overview
This project was built to simulate a music library and playlist management system through a graphical user interface. It brings together Python programming, Tkinter-based interaction, and modular class design in a practical coursework application.

## Key Features
- GUI-based music application
- Track browsing and viewing
- Playlist creation and management
- Track rating updates
- Add new tracks through a form
- Audio playback support
- CSV save and load functionality
- Structured object-oriented design

## Technologies Used
- Python
- Tkinter
- CSV
- Object-Oriented Programming

## System Design
The application follows a modular structure with separate classes and components for:
- track viewing
- playlist creation
- track updating
- track adding
- playback handling
- library management

## Purpose
The goal of this project was to improve practical skills in Python development, GUI programming, software structure, and object-oriented design.
