# JukeBox

JukeBox is a Python-based desktop application developed as part of university coursework, focused on GUI interaction, object-oriented programming, and structured feature implementation.

## Technologies Used
- Python
- Tkinter
- CSV

## Features
- GUI-based interaction
- Track and playlist management
- File handling and data persistence
- Structured object-oriented design

## Project Purpose
This project was developed to strengthen practical skills in Python programming, GUI development, and software structure.
